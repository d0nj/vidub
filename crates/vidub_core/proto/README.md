# Vendored Riva ASR protos

Upstream: <https://github.com/nvidia-riva/common> (MIT).

(`main` HEAD at vendor time, 2026-08-13).

Files (from `riva/proto/` in the upstream repo):

Vendored layout mirrors upstream (`riva/proto/*.proto` under `proto/`) so
`riva_asr.proto`'s `import "riva/proto/..."` statements resolve unmodified
with include dir `proto/`.

- `riva_asr.proto` — `nvidia.riva.asr.RivaSpeechRecognition` (`Recognize` unary).
- `riva_audio.proto` — `nvidia.riva.AudioEncoding` (`LINEAR_PCM`).
- `riva_common.proto` — `nvidia.riva.RequestId`.

Used for the NVCF gRPC Whisper fallback: `grpc.nvcf.nvidia.com:443` TLS,
metadata `authorization: Bearer <key>` + `function-id` (from workspace-root
`models.toml`, not code). Code is generated by `build.rs` via
`tonic_prost_build` with a vendored `protoc` (`protoc-bin-vendored`) — no
system `protoc` needed.
